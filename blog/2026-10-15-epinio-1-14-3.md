This release includes the usual bug fixes, dependency updates, and maintenance, along with OCI registry support for app charts.

We encourage you to review the documentation for [upgrading Epinio](https://docs.epinio.io/reference/upgrading).

<!-- truncate -->

## New Features and Improvements

- [App charts](https://docs.epinio.io/reference/concepts/appcharts#chart-sources) can now be sourced from OCI registries, alongside the existing support for remote sources. You can also push a packaged chart to Epinio's registry with [`epinio app chart push`](https://docs.epinio.io/reference/cli/app/chart/epinio_app_chart_push).
- Improved UI loading performance by caching Epinio resources.
- A stateful app chart now ships with Epinio by default, so you can deploy stateful applications without providing your own chart.
- Dex connectors can now be [configured through Helm chart values](https://docs.epinio.io/reference/security/authentication_oidc#configuring-dex), allowing for more flexible authentication setups.

## Fixes

- Fixed a bug where certain service instance configurations were not correctly applied during deployment.
- Fixed an issue where the Rancher extension did not allow external calls to Git providers.
- Fixed an issue where certain Docker Hub or Harbor registries were not correctly recognized due to missing CA certificates.
- Fixed an issue in the Helm chart where the `ingress.tls.enabled` value was not correctly applied, leading to misconfigured ingress resources.
- Fixed registry storage permission issues: `fsGroup` and `fsGroupChangePolicy` for the container registry can now be set through Helm chart values. See [File ownership](https://docs.epinio.io/how-to/operator/cluster-config/persistent_storage#file-ownership).

## MCP

- [MCP authentication](https://docs.epinio.io/reference/mcp#how-it-connects) is now per user, giving more granular access control and improved security.

## Documentation

- Added [Using a chart from another OCI registry](https://docs.epinio.io/how-to/operator/customization/create_custom_appcharts#using-a-chart-from-another-oci-registry) and [Pushing the chart to Epinio's registry](https://docs.epinio.io/how-to/operator/customization/create_custom_appcharts#pushing-the-chart-to-epinios-registry).
- Added [Running the registry and SeaweedFS on persistent storage](https://docs.epinio.io/how-to/operator/cluster-config/persistent_storage).
- Rewrote [OIDC authentication](https://docs.epinio.io/reference/security/authentication_oidc) around the new Dex Helm values, including keeping client secrets out of values.
- Updated [Installing the Epinio MCP Server](https://docs.epinio.io/getting-started/install-mcp) and the [MCP reference](https://docs.epinio.io/reference/mcp) for per-user authentication.

## Dependency updates

Updated server, UI, and Helm chart dependencies.
